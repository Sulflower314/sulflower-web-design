# Notice

`sulflower-web-design` is an independent adaptation of an earlier MIT-licensed `web-design-engineer` skill.

The preserved material includes the core visual-design philosophy, color-system approach, anti-cliché guidance, design-direction catalog, critique model, implementation patterns, and anchored style recipes.

Version 2.0 introduces a new name and invocation, four work modes, repository-native implementation guidance, risk-based confirmation, proportional v0 and variant behavior, brand-asset rights tracking, accessibility, performance, quality assurance, and GitHub-ready project packaging. These changes are maintained by Sulflower.
