# Brand Assets and Usage Rights

Use this reference for branded work, asset sourcing, or any deliverable intended for public distribution.

## Recognition order

Prioritize identity-bearing assets in this order:

1. Real logo, including light and dark variants where available.
2. Product imagery for physical products.
3. Representative UI captures for digital products.
4. Color tokens.
5. Typography.

A color palette alone is not a brand.

## Sourcing order

Prefer sources in this order:

1. User-provided and authorized assets.
2. Official press kit, brand site, media kit, or repository assets.
3. Official store listings or release material.
4. Clearly licensed public repositories or media libraries.
5. AI-generated supporting imagery based on authorized references, with disclosure when relevant.
6. An honest asset-pending placeholder.

Public availability does not imply redistribution rights. Do not package assets whose license is unclear.

Keep private source URLs, credentials, tokens, personal filesystem paths, and internal identifiers out of published artifacts.

## Fallbacks

- Missing logo: ask for it or use a clearly labeled pending state.
- Missing product imagery: use an authorized neutral placeholder with the required ratio.
- Missing UI capture: use a truthful low-detail structural mock rather than fabricated product data.
- Missing icon: use the project's icon system or a labeled placeholder.
- Missing font license: choose an authorized substitute and document the substitution.

Do not redraw a recognizable product as a CSS silhouette, invent a brand mark, fabricate partnerships, or present generated content as official material.
